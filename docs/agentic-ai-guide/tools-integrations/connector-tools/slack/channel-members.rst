.. container:: tutorial-intro

   Lists the members of one channel, one row per member with the user ID in id. User get turns an ID into a name and email.

Before you start
----------------

* A Slack connection. See :doc:`how to set one up <../slack>`.

Add it to your agent
--------------------

#. In Agent Studio, open the **Tools** group and click **Add tools**, or click **+ Tool** on an Agent Node.
#. Choose **Slack** under **Connectors** and connect your Slack connection.
#. Tick **members** in the **Channel** row, then click **Add to agent**.

The agent now sees ``slack_channel_members`` and calls it when a request needs it.

What the agent fills in
-----------------------

The agent fills these in from each request. To pin a value so the agent cannot change it, set it under **Fixed settings**.

.. list-table::
   :header-rows: 1
   :widths: 22 14 12 52
   :class: tool-params

   * - Parameter
     - Type
     - Required
     - What it means
   * - ``channel``
     - text
     - Yes
     - The channel ID, for example C0123ABC; Channel getMany finds it from the channel's name.
   * - ``limit``
     - whole number
     - No
     - How many members at most. Default: 100.

Need it on every run?
---------------------

To run **List channel members** every time a flow reaches it, without the agent deciding, use the :doc:`List channel members App Action </agentic-ai-guide/tools-integrations/app-action-apps/slack/channel-members>`.
