Send an email
=============

.. container:: tutorial-intro

   Sends an email from the mailbox and returns the sent message's id, threadId and labelIds.

Before you start
----------------

* A Google connection. See :doc:`how to set one up </agentic-ai-guide/tools-integrations/connector-tools/gmail>`.
* The account behind the connection must be allowed to change this data in Gmail.

Add this step
-------------

#. Drag **App Action** from **Commonly used** onto the canvas and connect it where the step belongs.
#. **App:** choose **Gmail**.
#. **Action:** under **Message**, choose **Send an email**.
#. **Details:** choose your Google connection, click **Test**, then fill in the boxes below.
#. Click **Save action**.

Fill in the details
-------------------

Type a value, or click a field under **What arrives here** to put a value from an earlier step into the box.

.. list-table::
   :header-rows: 1
   :widths: 26 12 62
   :class: tool-params

   * - Box
     - Required
     - What to enter
   * - **Mailbox**
     - No
     - Blank means the mailbox the connection belongs to.

Under **Advanced settings**:

.. list-table::
   :header-rows: 1
   :widths: 26 12 62
   :class: tool-params

   * - Box
     - Required
     - What to enter
   * - **If a row is rejected**
     - No
     - stop fails the run at the first rejected row. continue writes the rest and marks that row failed in result\_status and result\_error. Choices: ``stop``, ``continue``. Default: ``stop``.

Fields to set
-------------

Each row that arrives is written to Gmail. When its columns already have these names, leave **Fields to set** empty. Otherwise click the chip of a field to add it, then type its value or click one under **What arrives here**.

.. list-table::
   :header-rows: 1
   :widths: 24 22 54
   :class: tool-params

   * - Field
     - Column name
     - Example or hint
   * - **To**
     - ``to``
     - ``asha@example.com``
   * - **Subject**
     - ``subject``
     - ``Invoice 1042``
   * - **Body**
     - ``body``
     - ``Hi Asha, the invoice is attached to the portal.``
   * - **Cc**
     - ``cc``
     - ``ravi@example.com``
   * - **Bcc**
     - ``bcc``
     - Comma-separated
   * - **HTML body**
     - ``html``
     - 
   * - **Reply in thread**
     - ``threadId``
     - ``18c3f2a9b7d4e1f0``
   * - **In reply to**
     - ``inReplyTo``
     - ``<CAF1a2b3c@mail.gmail.com>``
   * - **From**
     - ``from``
     - ``billing@company.com``

What it passes on
-----------------

Every row comes out with three columns added, so the next step can route on them:

.. list-table::
   :header-rows: 1
   :widths: 26 74
   :class: tool-table

   * - Column
     - Value
   * - ``result_status``
     - ``ok``, ``failed`` or ``skipped``
   * - ``result_id``
     - The id Gmail gave the record
   * - ``result_error``
     - Why the row failed, if it did

Add a **Filter** on ``result_status = 'failed'`` to collect the rows that failed.

.. important::

   Running from the canvas is a preview: the write is skipped and ``result_status`` is ``skipped``. A full or scheduled run writes for real.

Let an agent decide instead
---------------------------

To let an agent call **Send an email** only when a request needs it, add the :doc:`Send an email tool </agentic-ai-guide/tools-integrations/connector-tools/gmail/message-send>` to an Agent Node.
