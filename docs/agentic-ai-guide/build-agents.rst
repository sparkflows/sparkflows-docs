Build AI Agents
===============

This page is a map. Building an agent in Sparkflows means working through the
steps below, and each one has a page of its own.

If you are starting from nothing, go straight to
:doc:`/agentic-ai-guide/quickstart` — it does steps 1 to 6 with a worked example
in about ten minutes.

The steps
---------

.. list-table::
   :header-rows: 1
   :widths: 6 32 62

   * - #
     - Step
     - Where it is covered
   * - 1
     - Decide Agent Studio or Agent Orchestration
     - :doc:`/agentic-ai-guide/concepts`
   * - 2
     - Create the agent and write its instructions
     - :doc:`/agentic-ai-guide/agent-studio`,
       :doc:`/agentic-ai-guide/models-prompts`
   * - 3
     - Choose the model and its generation settings
     - :doc:`/agentic-ai-guide/models-prompts`
   * - 4
     - Connect the credentials it needs
     - :doc:`/agentic-ai-guide/connections`
   * - 5
     - Add tools — connectors, built-in tools, MCP
     - :doc:`/agentic-ai-guide/tools-actions`,
       :doc:`/agentic-ai-guide/mcp-servers`
   * - 6
     - Ground it in your documents, if it needs them
     - :doc:`/agentic-ai-guide/rag-knowledge`
   * - 7
     - Give it workflows for exact, repeatable logic
     - :doc:`/agentic-ai-guide/workflows-as-tools`
   * - 8
     - Share rules across agents
     - :doc:`/agentic-ai-guide/skills`,
       :doc:`/agentic-ai-guide/context-agents-md`
   * - 9
     - Build the process — branches and multiple agents
     - :doc:`/agentic-ai-guide/multi-agent-orchestration`,
       :doc:`/agentic-ai-guide/control-flow`
   * - 10
     - Add human approval where the stakes justify it
     - :doc:`/agentic-ai-guide/human-in-the-loop`
   * - 11
     - Apply guardrails and access control
     - :doc:`/agentic-ai-guide/security-guardrails`
   * - 12
     - Test it, then ship it
     - :doc:`/agentic-ai-guide/evaluate-agents`,
       :doc:`/agentic-ai-guide/deploy-agents`

You will not need all twelve. Most agents are steps 2, 3, 5 and 12.
