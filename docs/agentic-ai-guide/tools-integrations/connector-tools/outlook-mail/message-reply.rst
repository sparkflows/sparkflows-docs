Reply to an email
=================

.. container:: tutorial-intro

   Replies to the sender of an email in the same conversation, with the reply text above the quoted original. Use Message replyAll to answer everyone on the email, and Message send to start a new conversation.

Before you start
----------------

* A Microsoft Graph connection. See :doc:`how to set one up <../outlook-mail>`.
* The account behind the connection must be allowed to change this data in Outlook Mail.

Add it to your agent
--------------------

#. In Agent Studio, open the **Tools** group and click **Add tools**, or click **+ Tool** on an Agent Node.
#. Choose **Outlook Mail** under **Connectors** and connect your Microsoft Graph connection.
#. Tick **reply** in the **Message** row, then click **Add to agent**.

The agent now sees ``outlook_mail_message_reply`` and calls it when a request needs it.

What the agent fills in
-----------------------

The agent fills these in from each request. To pin a value so the agent cannot change it, set it under **Fixed settings**.

.. list-table::
   :header-rows: 1
   :widths: 22 14 12 52
   :class: tool-params

   * - Parameter
     - Type
     - Required
     - What it means
   * - ``mailbox``
     - text
     - Yes
     - The address of the mailbox the email is in; the reply is sent from it. Example: asha.rao@contoso.com.
   * - ``messageId``
     - text
     - Yes
     - The id of the email to reply to, from the id column of Message getMany or Message search. Example: AAMkAGI2TG93AAA=.
   * - ``body``
     - text
     - Yes
     - The reply as plain text. Example: Thanks, received. We will pay it this week.

.. note::

   Each call waits for :doc:`your approval </agentic-ai-guide/safety-guardrails/human-in-the-loop>` before it changes anything in Outlook Mail.

Need it on every run?
---------------------

To run **Reply to an email** every time a flow reaches it, without the agent deciding, use the :doc:`Reply to an email App Action </agentic-ai-guide/tools-integrations/app-action-apps/outlook-mail/message-reply>`.
