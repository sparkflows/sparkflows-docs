.. container:: tutorial-intro

   Lists the tables in one schema, one row per table with its schema and name. Use it to find what the database holds; Table describe then gives a table's columns.

Before you start
----------------

* A MySQL connection. See :doc:`how to set one up <../mysql>`.

Add it to your agent
--------------------

#. In Agent Studio, open the **Tools** group and click **Add tools**, or click **+ Tool** on an Agent Node.
#. Choose **MySQL** under **Connectors** and connect your MySQL connection.
#. Tick **listTables** in the **Table** row, then click **Add to agent**.

The agent now sees ``mysql_table_listtables`` and calls it when a request needs it.

What the agent fills in
-----------------------

The agent fills these in from each request. To pin a value so the agent cannot change it, set it under **Fixed settings**.

.. list-table::
   :header-rows: 1
   :widths: 22 14 12 52
   :class: tool-params

   * - Parameter
     - Type
     - Required
     - What it means
   * - ``schema``
     - text
     - No
     - The database (MySQL's word for a schema) to list; blank lists the connection's default. Example: sales.

Need it on every run?
---------------------

To run **List tables** every time a flow reaches it, without the agent deciding, use the :doc:`List tables App Action </agentic-ai-guide/tools-integrations/app-action-apps/mysql/table-listtables>`.
