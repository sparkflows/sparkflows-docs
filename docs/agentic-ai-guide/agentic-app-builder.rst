Agentic App Builder
===================

Build business-facing applications in Sparkflows by combining agentic workflows with chat, forms, tables, dashboards, inputs, and actions.

Agentic App Builder turns Sparkflows agents and workflows into purpose-built applications without requiring users to interact directly with workflow definitions. User input can be passed into an agent or workflow, Sparkflows can execute the required data, AI, ML, retrieval, and business logic, and the resulting output can be presented back through the application.

The application layer and intelligence layer remain connected, allowing teams to move from an internal workflow to a usable enterprise application without creating a completely separate front end and integration layer for every use case.

Steps to Build an Agentic App
-----------------------------

Build an Agentic App by working through the following steps.

Step 1: Create the Application
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create an application and configure its basic properties.

Step 2: Design Pages & Layouts
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Design application pages and layouts for the intended user experience.

Step 3: Add Forms & Inputs
~~~~~~~~~~~~~~~~~~~~~~~~~~

Add forms and input components to capture information required by agents and workflows.

Step 4: Add Chat & Application Components
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create conversational experiences and add tables, charts, dashboards, buttons, and other interface components as required.

Step 5: Connect an Agent
~~~~~~~~~~~~~~~~~~~~~~~~

Connect an agent to provide the application's intelligence and process user requests.

Step 6: Connect a Workflow
~~~~~~~~~~~~~~~~~~~~~~~~~~

Connect Sparkflows workflows to trigger data, AI, ML, retrieval, and business logic from the application.

Step 7: Pass Parameters
~~~~~~~~~~~~~~~~~~~~~~~

Pass user inputs and application context into agents and workflows.

Step 8: Display Results
~~~~~~~~~~~~~~~~~~~~~~~

Configure how conversational responses, generated outputs, structured data, and AI-generated insights are presented to users.

Step 9: Build Multi-Stage Experiences
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create applications that span multiple workflow stages and user interactions.

Step 10: Add Custom Logic
~~~~~~~~~~~~~~~~~~~~~~~~~

Extend application behavior with supported custom logic where required.

Step 11: Configure Access & Publish
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Control application access and publish the Agentic App to its intended users.

Next Step
---------

Once the Agentic App is built and published, use Monitor & Govern to track its production usage, executions, and operational behavior.
