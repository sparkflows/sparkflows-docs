List leads
==========

.. container:: tutorial-intro

   Queries leads with an optional SOQL condition and returns up to limit rows.

Before you start
----------------

* A Salesforce connection. See :doc:`how to set one up </agentic-ai-guide/tools-integrations/connector-tools/salesforce>`.

Add this step
-------------

#. Drag **App Action** from **Commonly used** onto the canvas and connect it where the step belongs.
#. **App:** choose **Salesforce**.
#. **Action:** under **Lead**, choose **List leads**.
#. **Details:** choose your Salesforce connection, click **Test**, then fill in the boxes below.
#. Click **Load the fields from Salesforce** so later steps can use the columns, then **Save action**.

Fill in the details
-------------------

Type a value, or click a field under **What arrives here** to put a value from an earlier step into the box.

.. list-table::
   :header-rows: 1
   :widths: 26 12 62
   :class: tool-params

   * - Box
     - Required
     - What to enter
   * - **Where clause**
     - No
     - A filter in SOQL syntax, without the word WHERE. Blank returns everything up to the limit. For example ``Industry = 'Energy' AND AnnualRevenue > 1000000``.
   * - **Fields to return**
     - No
     - Comma-separated field names. Blank returns the standard fields. For example ``Id, Name, Industry, Owner.Name``.
   * - **Limit**
     - No
     - How many rows at most. A run from the canvas previews 20. Default: ``100``.

Under **Advanced settings**:

.. list-table::
   :header-rows: 1
   :widths: 26 12 62
   :class: tool-params

   * - Box
     - Required
     - What to enter
   * - **Nested fields**
     - No
     - deep spreads nested objects all the way into dotted columns, for example fields.priority.name. oneLevel stops after one level (fields.priority holds JSON). json keeps each object as one JSON text column. Choices: ``deep``, ``oneLevel``, ``json``. Default: ``deep``.

What it passes on
-----------------

The records come out as rows, one per record. Click **Load the fields from Salesforce** to see the columns before you save.

A run from the canvas previews 20 rows, whatever **Limit** says.

Start a flow from it
--------------------

A :doc:`Trigger </agentic-ai-guide/triggers-automation/triggers>` can watch Salesforce with this action and start the flow when something new turns up. Pick **Salesforce** in the Trigger, then the event.

.. list-table::
   :header-rows: 1
   :widths: 32 68
   :class: tool-table

   * - Event
     - What it reports
   * - **Lead created**
     - Reports each lead created since the last check, with its standard fields.
   * - **Lead updated**
     - Reports each lead every time it is changed, with its standard fields.
   * - **Lead created matching a condition**
     - Filter is a SOQL condition without WHERE, for example LeadSource = 'Web' AND Country = 'India'. Reports each lead created since the last check that meets it.
   * - **Lead converted**
     - Reports each lead converted since the last check, with the account, contact and opportunity it became in ConvertedAccountId, ConvertedContactId and ConvertedOpportunityId.

Let an agent decide instead
---------------------------

To let an agent call **List leads** only when a request needs it, add the :doc:`List leads tool </agentic-ai-guide/tools-integrations/connector-tools/salesforce/lead-getmany>` to an Agent Node.
