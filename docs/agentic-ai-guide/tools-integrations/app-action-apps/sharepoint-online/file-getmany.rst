List files in a folder
======================

.. container:: tutorial-intro

   Lists the files and folders directly inside one folder of the site's default document library, each with id, name, type, path, size, web address and who last changed it and when.

Before you start
----------------

* A Microsoft Graph or SharePoint connection. See :doc:`how to set one up </agentic-ai-guide/tools-integrations/connector-tools/sharepoint-online>`.

Add this step
-------------

#. Drag **App Action** from **Commonly used** onto the canvas and connect it where the step belongs.
#. **App:** choose **SharePoint**.
#. **Action:** under **File**, choose **List files in a folder**.
#. **Details:** choose your Microsoft Graph or SharePoint connection, click **Test**, then fill in the boxes below.
#. Click **Load the fields from SharePoint** so later steps can use the columns, then **Save action**.

Fill in the details
-------------------

Type a value, or click a field under **What arrives here** to put a value from an earlier step into the box.

.. list-table::
   :header-rows: 1
   :widths: 26 12 62
   :class: tool-params

   * - Box
     - Required
     - What to enter
   * - **Site**
     - No
     - The site's URL, name or id. Blank uses the site on the connection.
   * - **File, folder, list or item**
     - No
     - A file or folder by id or path (TestData/Reports), the list for List operations, or the item id for List Item operations. For example ``TestData/Reports, or an item id``.
   * - **Fields to return**
     - No
     - Comma-separated field names. Blank returns the default set. For example ``name, path, size, webUrl``.
   * - **Limit**
     - No
     - How many rows at most. A run from the canvas previews 20. Default: ``100``.

Under **Advanced settings**:

.. list-table::
   :header-rows: 1
   :widths: 26 12 62
   :class: tool-params

   * - Box
     - Required
     - What to enter
   * - **Extra query parameters (JSON)**
     - No
     - Sent to the API unchanged, for a filter this form has no field for. For example {"timeMin": "2026-09-01T00:00:00Z"}.
   * - **Nested fields**
     - No
     - Some records keep a value inside another value, such as a priority inside an issue. This decides how those inner values become columns.

       * ``deep`` (default): Every inner value gets its own column, named with dots, such as ``fields.priority.name``.
       * ``oneLevel``: Only the first level is split. Anything deeper stays in one column as JSON text.
       * ``json``: Each inner value stays whole, in one column of JSON text.

       See the example below the table.

**Nested fields, by example.** Take a record ``{"id": 7, "fields": {"priority": {"name": "High"}}}``. Each choice gives you these columns:

.. list-table::
   :header-rows: 1
   :widths: 20 80
   :class: tool-table

   * - Choice
     - Columns you get
   * - ``deep``
     - ``id`` = ``7`` and ``fields.priority.name`` = ``High``
   * - ``oneLevel``
     - ``id`` = ``7`` and ``fields.priority`` = ``{"name": "High"}``
   * - ``json``
     - ``id`` = ``7`` and ``fields`` = ``{"priority": {"name": "High"}}``

Keep ``deep`` unless a later step needs the whole inner value as JSON.

What it passes on
-----------------

The records come out as rows, one per record. Click **Load the fields from SharePoint** to see the columns before you save.

A run from the canvas previews 20 rows, whatever **Limit** says.

Start a flow from it
--------------------

A :doc:`Trigger </agentic-ai-guide/triggers-automation/triggers>` can watch SharePoint with this action and start the flow when something new turns up. Pick **SharePoint** in the Trigger, then the event.

.. list-table::
   :header-rows: 1
   :widths: 32 68
   :class: tool-table

   * - Event
     - What it reports
   * - **File added to a folder**
     - Folder is a folder in the site's default library, a path such as Finance/Invoices, or / for the top. The first check records its files; later checks report each file that appears directly in it. Site is the site's address, which a SharePoint connection can already hold.
   * - **File added or changed in a folder**
     - Folder is a folder in the site's default library, a path such as TestData, or / for the top. Reports each file directly in it that is added or saved since the last check. Site is the site's address, which a SharePoint connection can already hold.
   * - **Folder created in a folder**
     - Folder is a folder in the site's default library, a path such as Finance, or / for the top. The first check records its folders; later checks report each folder created directly inside it. Site is the site's address, which a SharePoint connection can already hold.

Let an agent decide instead
---------------------------

To let an agent call **List files in a folder** only when a request needs it, add the :doc:`List files in a folder tool </agentic-ai-guide/tools-integrations/connector-tools/sharepoint-online/file-getmany>` to an Agent Node.
