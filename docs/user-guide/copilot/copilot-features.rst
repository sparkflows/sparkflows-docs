AI Assistant Additional Features 
=========================================

This document describes the additional features available in AI Assistant within Sparkflows in both the Workflow Designer and the Pipeline Designer, including Feedback, Reports, and Report Email Configuration.

AI Assistant Feedback
---------------------

 .. figure:: ../../_assets/user-guide/copilot/Copilot-Add-On-Features/copilot-report-feedback.png
     :alt: copilot features
     :width: 60%

**Add Feedback**
+++++++++++++++++++

* When a user clicks on **Feedback**, they can submit feedback on the AI Assistant's response.

 .. figure:: ../../_assets/user-guide/copilot/Copilot-Add-On-Features/copilot-add-feedback.png
     :alt: copilot features
     :width: 60%

* This allows users to share their experience, provide suggestions and highlight concerns related to the response generated by AI Assistant.



**View Feedback**
+++++++++++++++++++

* Admins can view user feedback in the AI Assistant window under: **Administration --> Feedbacks** tab

 .. figure:: ../../_assets/user-guide/copilot/Copilot-Add-On-Features/copilot-feedback-list.png
     :alt: copilot features
     :width: 60%

* This section displays all submitted feedback for review and analysis.


AI Assistant Report
-------------------

 .. figure:: ../../_assets/user-guide/copilot/Copilot-Add-On-Features/copilot-report-feedback.png
     :alt: copilot features
     :width: 60%

**Add Report**
+++++++++++++++++++

* When a user clicks on **Report**, they can report an issue with the AI Assistant response.

 .. figure:: ../../_assets/user-guide/copilot/Copilot-Add-On-Features/copilot-add-report.png
     :alt: copilot features
     :width: 60%

* This feature is used to flag incorrect and problematic responses generated by AI Assistant.



**View Report**
+++++++++++++++++++

* Admins can view user reports in the AI Assistant window under: **Administration --> Reports** tab

 .. figure:: ../../_assets/user-guide/copilot/Copilot-Add-On-Features/copilot-report-list.png
     :alt: copilot features
     :width: 60%

* This section lists all reported issues for further investigation and action.


Configuring Report Emails
-------------------------

* Users can configure email addresses while creating or updating a AI Assistant. When an issue is reported, the report will be sent to the configured email addresses.

 .. figure:: ../../_assets/user-guide/copilot/Copilot-Add-On-Features/copilot-report-email-config.png
     :alt: copilot features
     :width: 60%

* Once a user submits a report, an email notification will be sent to the configured recipients, as shown below.

     :alt: copilot features
