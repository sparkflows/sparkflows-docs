Build
==========

Build enterprise AI agents in Sparkflows using visual agentic workflows that combine AI models, enterprise data, tools, business logic, and actions.

Sparkflows provides a visual environment for designing agent behavior and execution logic without requiring the entire application to be assembled in code. Using reusable processors and workflow components, teams can connect agents to enterprise data, configure LLMs, add tools and retrieval, incorporate AI/ML models, and define the steps an agent follows to complete a task.

Agents can be designed for a focused task or used as part of a larger orchestrated process. A workflow can combine deterministic rules and transformations with AI-driven reasoning, allowing data preparation, model predictions, retrieval, tool calls, approvals, and agent decisions to operate within the same flow.

Steps to Build an Agent
-----------------------

Build an agent by working through the following steps.

Step 1: Create & Define the Agent
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create an agent and define its role, goal, instructions, inputs, outputs, and execution behavior.

Step 2: Configure Models & Prompts
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Select the required models and configure prompts and model parameters.

Step 3: Connect Enterprise Data
~~~~~~~~~~~~~~~~~~~~~~~~~~

Connect the enterprise data required by the agent.

Step 4: Add RAG & Knowledge
~~~~~~~~~~~~~~~~~~~~~~

Add documents, knowledge sources, and retrieval where the agent requires grounded information.

Step 5: Add Tools & Actions
~~~~~~~~~~~~~~~~~~~~~~

Connect APIs, applications, databases, workflows, and other tools required by the agent.

Step 6: Build the Agentic Workflow
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Combine models, data, tools, processors, business logic, and actions into the workflow that defines how the agent performs its task.

Step 7: Orchestrate Multiple Agents
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Coordinate specialized agents when the process requires multiple agents working together.

Step 8: Add Human-in-the-Loop
~~~~~~~~~~~~~~~~~~~~~~~~

Add approvals, reviews, escalation, and human decision points where required.

Step 9: Apply Security & Guardrails
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Control access to data, tools, outputs, actions, and other aspects of agent behavior.

Next Step
---------

Once the agent is built, continue to Evaluate to test its behavior and validate its results.
