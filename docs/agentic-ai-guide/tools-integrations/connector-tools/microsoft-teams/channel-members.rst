.. container:: tutorial-intro

   Lists the members of one channel with displayName, email, userId and roles. A standard channel has the team's members; private and shared channels have their own.

Prerequisites
-------------

* **Connection:** Microsoft Graph connection. See :doc:`the Microsoft Teams prerequisites <../microsoft-teams>`.

Parameters
----------

As an agent tool, the model fills in each parameter unless you fix it under **Fixed settings**, and in an App Action each one is a box on the **Details** step.

.. list-table::
   :header-rows: 1
   :widths: 18 17 11 12 42
   :class: tool-params

   * - Parameter
     - App Action input
     - Type
     - Required
     - Description
   * - ``teamId``
     - Team
     - text
     - Yes
     - The team id (a GUID), from Team getMany. Example: b1f0c3d2-1234-4c5d-9e8f-0a1b2c3d4e5f.
   * - ``channelId``
     - Channel
     - text
     - Yes
     - The channel id, for example 19:a1b2c3d4e5f6@thread.tacv2, from Channel getMany.
   * - ``limit``
     - Limit
     - whole number
     - No
     - How many members at most. Default: 50.

Use it
------

**As an agent tool.** Open the Agent Node's **+ Tool**, choose **Microsoft Teams**, connect, and tick **members** in the **Channel** row. The model sees it as ``msteams_channel_members``.

**As an App Action.** Drop **App Action** on the canvas, pick **Microsoft Teams**, then **List channel members**, and fill in the inputs above. It runs every time the flow reaches it.
