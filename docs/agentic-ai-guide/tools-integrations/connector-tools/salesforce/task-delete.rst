Delete a task
=============

.. container:: tutorial-intro

   Deletes one task by its Salesforce Id and returns that Id. Salesforce moves it to the Recycle Bin, where it can be restored for 15 days.

Before you start
----------------

* A Salesforce connection. See :doc:`how to set one up <../salesforce>`.
* The account behind the connection must be allowed to change this data in Salesforce.

Add it to your agent
--------------------

#. In Agent Studio, open the **Tools** group and click **Add tools**, or click **+ Tool** on an Agent Node.
#. Choose **Salesforce** under **Connectors** and connect your Salesforce connection.
#. Tick **delete** in the **Task** row, then click **Add to agent**.

The agent now sees ``salesforce_task_delete`` and calls it when a request needs it.

What the agent fills in
-----------------------

The agent fills these in from each request. To pin a value so the agent cannot change it, set it under **Fixed settings**.

.. list-table::
   :header-rows: 1
   :widths: 22 14 12 52
   :class: tool-params

   * - Parameter
     - Type
     - Required
     - What it means
   * - ``taskId``
     - text
     - Yes
     - The Salesforce Id of the task to delete, starting 00T, for example 00TXX000003QrSt; List tasks returns it.

.. note::

   Each call waits for :doc:`your approval </agentic-ai-guide/safety-guardrails/human-in-the-loop>` before it changes anything in Salesforce.

Need it on every run?
---------------------

To run **Delete a task** every time a flow reaches it, without the agent deciding, use the :doc:`Delete a task App Action </agentic-ai-guide/tools-integrations/app-action-apps/salesforce/task-delete>`.
