Count accounts
==============

.. container:: tutorial-intro

   Counts the accounts that match a SOQL condition and returns one row with the total, without fetching the records. Use List accounts to see the records themselves.

Prerequisites
-------------

* **Connection:** Salesforce connection. See :doc:`the Salesforce prerequisites <../salesforce>`.

Parameters
----------

As an agent tool, the model fills in each parameter unless you fix it under **Fixed settings**, and in an App Action each one is a box on the **Details** step.

.. list-table::
   :header-rows: 1
   :widths: 18 17 11 12 42
   :class: tool-params

   * - Parameter
     - App Action input
     - Type
     - Required
     - Description
   * - ``where``
     - Where
     - text
     - No
     - A SOQL condition without the word WHERE, such as Industry = 'Energy' AND AnnualRevenue > 1000000, with text in single quotes, dates unquoted and no ORDER BY or LIMIT; blank counts every account.

Use it
------

**As an agent tool.** Open the Agent Node's **+ Tool**, choose **Salesforce**, connect, and tick **count** in the **Account** row. The model sees it as ``salesforce_account_count``.

**As an App Action.** Drop **App Action** on the canvas, pick **Salesforce**, then **Count accounts**, and fill in the inputs above. It runs every time the flow reaches it.
