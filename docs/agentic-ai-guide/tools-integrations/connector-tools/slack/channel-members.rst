List channel members
====================

.. container:: tutorial-intro

   Lists the members of one channel, one row per member with the user ID in id. User get turns an ID into a name and email.

Prerequisites
-------------

* **Connection:** Slack connection. See :doc:`the Slack prerequisites <../slack>`.

Parameters
----------

As an agent tool, the model fills in each parameter unless you fix it under **Fixed settings**, and in an App Action each one is a box on the **Details** step.

.. list-table::
   :header-rows: 1
   :widths: 18 17 11 12 42
   :class: tool-params

   * - Parameter
     - App Action input
     - Type
     - Required
     - Description
   * - ``channel``
     - Channel
     - text
     - Yes
     - The channel ID, for example C0123ABC; Channel getMany finds it from the channel's name.
   * - ``limit``
     - Limit
     - whole number
     - No
     - How many members at most. Default: 100.

Use it
------

**As an agent tool.** Open the Agent Node's **+ Tool**, choose **Slack**, connect, and tick **members** in the **Channel** row. The model sees it as ``slack_channel_members``.

**As an App Action.** Drop **App Action** on the canvas, pick **Slack**, then **List channel members**, and fill in the inputs above. It runs every time the flow reaches it.
