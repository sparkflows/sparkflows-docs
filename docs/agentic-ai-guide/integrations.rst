Integrations & Enterprise Data
==============================

Enterprise agents are most useful when they can work with the systems where business data and actions already live. Sparkflows connects visual workflows to databases, warehouses, data lakes, files, cloud platforms, APIs, enterprise applications, AI services, and other supported systems.

Connections are reusable platform objects that allow workflows to access external systems without embedding credentials directly into workflow logic. Once configured, the same connection can support data engineering, analytics, ML, RAG, agent tools, and Agentic Apps as appropriate.

Integration documentation should cover both connectivity and usage: how to create and test a connection, authenticate securely, use the connected system in a workflow, and troubleshoot common issues.

Steps to Integrate Enterprise Data & Systems
--------------------------------------------

Integrate enterprise data and systems by working through the following steps.

Step 1: Identify Required Systems
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Identify the databases, data platforms, files, APIs, applications, AI services, or other enterprise systems required by the agent.

Step 2: Create & Test a Connection
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Create the required reusable connection and validate connectivity.

Step 3: Configure Authentication
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Configure credentials, tokens, and other authentication required to access the system.

Step 4: Configure Permissions
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Apply the permissions required for the agent or workflow to access the connected system.

Step 5: Connect Enterprise Data
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Connect supported databases, warehouses, data lakes, cloud storage, files, and documents to the workflow.

Step 6: Connect APIs & Applications
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Connect external systems through REST APIs and supported enterprise applications.

Step 7: Connect Cloud & AI Services
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Connect supported AWS, Azure, GCP, LLM providers, and other cloud or AI services.

Step 8: Connect Vector Databases
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Connect supported vector stores for workflows that require retrieval and knowledge capabilities.

Step 9: Use the Connection in Workflows
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Use connected systems within data engineering, analytics, ML, RAG, agent tools, and Agentic Apps as appropriate.

Step 10: Configure Read & Write Operations
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Distinguish read operations from write or transactional operations and apply additional permissions or approval where appropriate.

Step 11: Manage Connections
~~~~~~~~~~~~~~~~~~~~~~~~~~

Review and maintain configured connections as enterprise integrations change.

Step 12: Troubleshoot Connectivity
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Diagnose connectivity, permissions, authentication, and credential issues.

Next Step
---------

Once the required enterprise systems and connections are configured and validated, use them within the agent workflow and continue to Evaluate to validate how the agent works with connected data and systems.
