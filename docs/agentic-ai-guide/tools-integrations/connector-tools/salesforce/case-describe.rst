====================

.. container:: tutorial-intro

   Lists every field on the Case object, one row per field with its API name, label, type, length and whether it can be blank or updated. Use it to learn the org's exact field names, custom \_\_c fields included, before a create, update or query.

Prerequisites
-------------

* **Connection:** Salesforce connection. See :doc:`the Salesforce prerequisites <../salesforce>`.

Parameters
----------

This tool takes no parameters.

Use it
------

**As an agent tool.** Open the Agent Node's **+ Tool**, choose **Salesforce**, connect, and tick **describe** in the **Case** row. The model sees it as ``salesforce_case_describe``.

**As an App Action.** Drop **App Action** on the canvas, pick **Salesforce**, then **Describe case fields**, and fill in the inputs above. It runs every time the flow reaches it.
