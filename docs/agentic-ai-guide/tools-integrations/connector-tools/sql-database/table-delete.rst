Delete rows
===========

.. container:: tutorial-intro

   Deletes the row whose key column equals keyValue, or every row matching where when no key value is given, and returns how many rows were deleted. It refuses to run with neither, so a whole table is never emptied by accident.

Before you start
----------------

* A Database connection. See :doc:`how to set one up <../sql-database>`.
* The account behind the connection must be allowed to change this data in SQL Database.

Add it to your agent
--------------------

#. In Agent Studio, open the **Tools** group and click **Add tools**, or click **+ Tool** on an Agent Node.
#. Choose **SQL Database** under **Connectors** and connect your Database connection.
#. Tick **delete** in the **Table** row, then click **Add to agent**.

The agent now sees ``database_table_delete`` and calls it when a request needs it.

What the agent fills in
-----------------------

The agent fills these in from each request. To pin a value so the agent cannot change it, set it under **Fixed settings**.

.. list-table::
   :header-rows: 1
   :widths: 22 14 12 52
   :class: tool-params

   * - Parameter
     - Type
     - Required
     - What it means
   * - ``table``
     - text
     - Yes
     - The table name as Table listTables returns it, for example customers or, with its schema, sales.customers, in letters, digits, underscore, dot and $ only (quoted names are refused).
   * - ``keyValue``
     - text
     - No
     - The key value of the row to delete; when set, where is not used. Example: 1042.
   * - ``keyColumn``
     - text
     - No
     - The column that holds the key; blank means id. Example: customer\_id.
   * - ``where``
     - text
     - No
     - A condition in the database's own SQL without the word WHERE, used when keyValue is blank as one condition, so a semicolon or a comment outside quoted text is refused; every matching row is deleted, for example status = 'cancelled'.
   * - ``schema``
     - text
     - No
     - The schema (a database on MySQL) that holds the table, when it is not the connection's default. Example: sales.

.. note::

   Each call waits for :doc:`your approval </agentic-ai-guide/safety-guardrails/human-in-the-loop>` before it changes anything in SQL Database.
