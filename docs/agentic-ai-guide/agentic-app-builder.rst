Agentic App Builder
=============

Agentic App Builder turns Sparkflows agents and workflows into business-facing applications. Instead of requiring users to interact directly with workflow definitions, teams can provide purpose-built experiences using chat, forms, tables, dashboards, inputs, and actions.

The application layer and intelligence layer remain connected. User input can be passed into an agent or workflow, Sparkflows can execute the required data, AI, ML, retrieval, and business logic, and the resulting output can be presented back through the application.

This enables teams to move from an internal workflow to a usable enterprise application without creating a completely separate front end and integration layer for every use case.

Start Here
-----------------

Start by creating an application and connecting it to an existing agent or workflow. Add the interface components required by the use case, define how user inputs are passed to the workflow, and configure how results are displayed.

Use Agentic Apps for experiences such as enterprise assistants, operational applications, guided decision flows, review and approval applications, dashboards, and workflow-driven forms.
