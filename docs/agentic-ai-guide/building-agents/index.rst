Building Agents
================

Building Agents covers the core components users configure when creating an AI agent in Sparkflows.
It explains how to use Agent Studio, models and prompts, Knowledge/RAG, Skills, and agent context.
Define how your agent behaves, what it knows, and the capabilities it can use to accomplish tasks.
